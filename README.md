## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Career application email

Career applications with a PDF, DOC, or DOCX attachment are sent to `careers@facebuilds.com` through Resend. Configure `RESEND_API_KEY` and `CAREER_EMAIL_FROM` in the deployment environment before enabling submissions. For local development, put both variables in the ignored `.env.local` file or export them before starting the dev server. The sender address must belong to a domain verified in Resend. See `.env.example` for the variable names. Never commit real API keys.
